# Compra Clara

App movil para controlar compras de supermercado con escaneo de codigos de barra, lista editable y total acumulado contra presupuesto.

## Uso

Publicar como sitio estatico en Vercel, Netlify o GitHub Pages. La camara requiere HTTPS en celulares.

## Archivos principales

- `index.html`: pantalla principal de la app.
- `styles.css`: diseno visual para celular.
- `app.js`: logica de escaneo, lista, presupuesto y busqueda de productos.
- `manifest.webmanifest`: configuracion para instalar como app.
- `sw.js`: cache basico para PWA.
- `icon.svg`: icono de la app.
- `vercel.json`: configuracion de despliegue en Vercel.
